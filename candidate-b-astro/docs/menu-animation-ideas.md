# Идеи анимации меню (пока НЕ внедрено)

Основа — правила из курса (`Animation_course.md`):

- UI-анимации держим около 200–300 мс; быстрее = «отзывчивее».
- Появление и исчезновение — `ease-out` (резкий старт, мягкая посадка). Для
  элементов, которые уже на экране и двигаются, — `ease-in-out`.
- Встроенные кривые CSS слабоваты — берём свои `cubic-bezier`. Уже добавлен
  `--ease-out-strong: cubic-bezier(0.23, 1, 0.32, 1)`.
- Не анимировать от `scale(0)` — начинать с 0.95 + opacity.
- Анимация «растёт из того места, откуда вызвана» (`transform-origin`).
- Hover — только на устройствах с мышью: `@media (hover: hover)`.
- Для «неидеального» fade можно добавить `filter: blur(2px)`.
- Не анимировать то, чем пользуются клавиатурой.

## Варианты для панели «Версия 1–5»

**V1 «Linear-like».** Панель за ~220 мс: opacity 0→1 + сдвиг на 6–8 px
вниз, `--ease-out-strong`. Пункты без каскада или с очень коротким (20 мс).
Самый ближний к эталону босса: быстро и сдержанно.

**V2 «Каскад».** Как сейчас, но быстрее: панель 260 мс, пункты по очереди
с шагом 35 мс. Ощущение «живого» меню.

**V3 «Clip-path раскрытие».** Панель раскрывается сверху вниз через
`clip-path: inset(0 0 100% 0)` → `inset(0)`, ~300 мс, `ease-out`. Эффект
«штора». Приём из раздела курса про clip-path.

**V4 «Из кнопки».** Панель растёт из точки бургера: `transform-origin: top
right`, `scale(0.95)` → `1` + opacity. Выглядит как у нативных меню.

**V5 «Blur-fade».** Только прозрачность + `blur(4px)` → `blur(0)`, без
движения. Самый спокойный вариант, хорошо для «дорогого» ощущения.

## Hover на десктопе (Company / Game / Careers)

**H1 «Плавающая пилюля» (как у Linear).** Один полупрозрачный фон под пунктами
плавно переезжает к пункту под курсором (JS считает `offsetLeft` и `width`
пункта). ~200 мс, `ease-out`. Рекомендую.

**H2 «Подчёркивание».** Линия растёт от центра к краям (`scaleX`).

**H3 «Затемнение остальных».** Пункт под курсором яркий, соседи тускнеют.

Правило: при быстром переходе между пунктами подсветка не «перезапускается», а
плавно едет — это и есть эффект Linear.
